MCP Server Implementation

FastAPI Server (Port 8001)

Endpoints:

  • GET /health
  • GET /tools/list
  • POST /tools/call/write_*
  • POST /tools/call/read_*
  • GET /reservations

Tools:

  • write_confirmed_reservation
  • read_confirmed_reservations

Auth: X-MCP-Token header

File Format Example

Integration with Stages 1 & 2

MCP Client

from mcp_server.client import MCPClient client = MCPClient( base_url="http://127.0.0.1:8001", token="secret-token" ) result = client.write_confirmed_reservation( reservation_id=1, first_name="Alice", last_name="Anderson", car_number="AAA-111", start_ts="2026-11-20T10:00:00", end_ts="2026-11-20T18:00:00" )
